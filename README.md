# FIXWIZ - AI powered troubleshooting assisstant

## snap it, tell it, fix it
## FIXWIZ is your ai troubleshooting companion for anything that breaks


## OVERVIEW

FIXWIZ uses gemini3 pro to analyze images, vids or livestreams of broken objects (furniture, appliances, electronics, etc) and provides step by step repair instructions
users can also provide **additional textual details** to refine the diagnosis thus enabling **multimodal reasoning**

built for **mobile first experience**, FIXWIZ is designed to be **interactive, intelligent, and world class hackathon ready**

## FEATURES

- **multimodal diagnosis:**
analyze photos, vids and livestreams of broken objects

- **interactive correction loop:**
users can provide extra textual details to refine the repair instructions

- **step by step guidance:**
gemini3 pro generates clear, actionable repair steps

- **history & tracking:**
save previous diagnosis and fixes for future refrence

- **mobile first design:**
built with **EXPO** for a smooth cross platform experience

- **backend powered AI:**
FastAPI backend integrates seamlessly with gemini3 pro and handles media processing

- **cloud ready storage:**
superbase used for storing thumbnails, key frames, and user history

## TECH STACK

- mobile: EXPO + react + TypeScript

- backend: FastAPI + python + Uvicorn

- AI: gemini3 pro (vision+reasoning+multimodal)

- storage: superbase

- caching & async: redis

## GETTING STARTED

### 1. backend setup
```
cd backend
python -m venv venv
venv\Scripts\activate   #widnows
source venv/bin/activate #linux/mac
pip install -r requirements.txt
uvicorn main:app --reload
```

### 2. mobile setup
```
cd mobile
npm install
npx expo start
```

### 3. environment variables

copy the **.env example** from **backend/** and make a new file named **.env** and put your own api keys


## USAGE

1. open the app on your device/emulator

2. capture an image or short video of the broken object

3. provide extra details about the issue

4. receive a step by step repair guide generated by gemini3 pro

5. save or track your repair in history

## WHY DID WE BUILD FIXWIZ?

**FIXWIZ** was created for the gemini3 hackathon by **google DeepMind** with a simple mission: empower people to troubleshoot and fix everyday broken objects faster and smarter using AI

during the hackathon, we noticed a common problem: most people struggle to diagnose issues with furniture, appliances, and electronics without expert help

traditional apps either focus on manuals, videos or one size fits all guides but none combine multimodal reasoningn interactive guidance, and real time feedback

FIXWIZ solves these problems by:

- **analyzing visual inputs**
users can take a photo, short video or a livestream of the broken item

- **refining diagnosis with user input**
users provide extra textual details for more accuracte, personnalized troubleshooting 

- **generating actionnable instructions**
gemini3 pro provides step by step repair guidance, making the process intuitive and interactive

- **saving history**
users can track previous diagnoses, creating a personal repair library

by combining gemini3 pro's multimodal reasoning, a mobile first design, and cloud assissted storage, FIXWIZ turns AI into a hands on intelligent assisstant that tackles real world problems not just toy demos!
